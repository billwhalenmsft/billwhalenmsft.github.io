Five official estimators answer five different bills. Here is how I pick, and how I check the estimate once things are live.

Every AI conversation I have ends at the same question: what will this cost to run? Microsoft and GitHub already publish good estimators. The mistake I see is opening the wrong one, or treating its answer as a quote.

Three habits that keep estimates honest

  1. Estimate a range, not a number. Run low, likely and high volumes. Microsoft's own guidance is to add a 10–20% buffer.
  2. Licenses change the math. Microsoft 365 Copilot licenses cover some Copilot Studio use for licensed employees, and Microsoft 365 E5/E7 includes a monthly SCU allowance for Security Copilot. Ask who's already licensed before you size.
  3. Measure after go-live. In Cowork, type /cost to see what a task used. Admins see the full picture in Microsoft 365 admin center → Copilot → Cost management, Power Platform admin center → Licensing, the Security Copilot usage dashboard, or GitHub billing settings. Re-size every quarter.
